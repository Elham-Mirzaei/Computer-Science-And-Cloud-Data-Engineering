# Computer Science & Cloud Data Engineering

**Building strong computer science foundations and applying them to modern cloud-native data engineering.**

This repository documents my technical development in computer science, software engineering, distributed systems, and cloud data engineering. It combines structured learning, practical implementations, technical notes, and engineering projects.

My goal is to develop a deeper understanding of the systems behind modern data platforms — from algorithms and operating systems to distributed processing, cloud infrastructure, and scalable data architectures.

---

## About Me

I have an academic background in Electrical Engineering and currently work as a Data Engineer.

While working with data systems, I have become increasingly interested in understanding the computer science principles behind the technologies I use: how systems manage resources, how databases store and retrieve information, how distributed applications communicate, and how cloud platforms support reliable and scalable data processing.

This repository is part of my journey toward strengthening those foundations and developing further expertise in Cloud Data Engineering.

I believe in learning beyond tools and frameworks: understanding the underlying principles, making informed engineering decisions, and applying theoretical knowledge to practical problems.

## Engineering Principles

Throughout this journey, I aim to apply the following principles:

- **Understand the fundamentals:** Learn how technologies work, not only how to use them.
- **Build through practice:** Translate theoretical concepts into working implementations.
- **Think in systems:** Understand interactions between components, infrastructure, data, and applications.
- **Document engineering decisions:** Explain design choices, trade-offs, and lessons learned.
- **Prioritize quality:** Apply testing, maintainability, security, and reliability principles.
- **Keep improving:** Review existing work and identify opportunities for improvement.
